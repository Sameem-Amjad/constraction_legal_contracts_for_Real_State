En cas de résiliation pour des raisons de commodité, aucune des parties n&#x27;aura d&#x27;autre responsabilité envers l&#x27;autre, à l&#x27;exception des obligations qui se sont accumulées avant la date de résiliation. Le Sous-traitant est rémunéré pour tous les Travaux exécutés jusqu&#x27;à la date de résiliation.</p>
<h2>21. Confidentialité et protection des données</h2>
<p>Les parties conviennent de préserver la confidentialité de toute information propriétaire, sensible ou personnelle obtenue l&#x27;une de l&#x27;autre ou du Propriétaire dans le cadre du présent Contrat. Chaque partie mettra en œuvre les mesures techniques et organisationnelles appropriées pour protéger ces informations contre l&#x27;accès, l&#x27;utilisation, la divulgation, l&#x27;altération ou la destruction non autorisés.</p>
<p>Les deux parties s&#x27;engagent à respecter les lois et règlements applicables en matière de protection des données, en veillant à ce que tout traitement de données à caractère personnel soit licite, équitable et transparent. Les parties veillent à ce que toute information sensible, y compris les données à caractère personnel, soit traitée en toute sécurité et uniquement aux fins pour lesquelles elle a été divulguée.</p>
<p>Aucune des parties ne divulguera d&#x27;informations confidentielles à un tiers sans le consentement écrit préalable de l&#x27;autre partie, sauf si est requis par la loi ou nécessaire à l&#x27;exécution des Travaux. En cas de violation de données ou de divulgation non autorisée, la partie affectée notifie l&#x27;autre partie dans les quarante-huit heures (48h) suivant la violation ou la divulgation et prend toutes les mesures nécessaires pour atténuer tout préjudice potentiel.</p>
<p>À la fin du présent Contrat, chaque partie doit retourner ou détruire en toute sécurité toutes les informations confidentielles et personnelles reçues de l&#x27;autre partie, à moins que la loi n&#x27;exige la conservation de ces informations.</p>
<h2>22. Résolution des différends</h2>
<p>En cas de différend survenant dans le cadre du présent Contrat, les parties se conforment à la procédure de résolution suivante :</p>
<h2>22.1 Négociation</h2>
<p>Les parties tentent d&#x27;abord de résoudre le différend par la négociation directe, dans un délai de trente (30) jours à compter de la survenance du différent.</p>
<h2>22.2 Médiation</h2>
<p>Si le différend n&#x27;est pas résolu par la négociation, les parties conviennent de le soumettre à la médiation. Un médiateur accrédité au Québec sera choisi d&#x27;un commun accord dans les [SUSP3] jours suivant la fin des négociations. Si les parties ne peuvent s&#x27;entendre sur le choix d&#x27;un médiateur, chaque partie propose un médiateur et ces médiateurs choisissent conjointement un troisième médiateur neutre pour mener la médiation.</p>
<h2>22.3 Calendrier de la médiation</h2>
<p>La médiation commence dans les [SUSP3] jours suivant la sélection du médiateur et se termine dans les soixante (60) jours, sauf entente contraire des parties par écrit.</p>
<h2>22.4 Coûts de la médiation</h2>
<p>Les coûts de la médiation sont partagés à parts égales entre les parties, sauf décision contraire du médiateur.</p>
<h2>22.5 Litiges</h2>
<p>Si la médiation ne permet pas de résoudre le différend, l&#x27;une ou l&#x27;autre des parties peut engager une procédure judiciaire. Les parties reconnaissent irrévocablement la compétence des tribunaux de l&#x27;arrondissement judiciaire où se trouve le Site du Projet.</p>
<p>Ces procédures assurent que les litiges sont traités de manière cohérente et efficace, conformément à l&#x27;esprit professionnel et coopératif voulu par les deux parties.</p>

<p>Le Sous-traitant doit fournir un personnel qualifié et correctement formé pour l&#x27;exécution des Travaux. Le Sous-traitant reste seul responsable de ses employés, sous-traitants et agents, y compris de toutes les retenues salariales, de l&#x27;assurance-emploi et de l&#x27;impôt sur le revenu.</p>
<h2>24. Santé et sécurité</h2>
<p>Les parties doivent se conformer à tous les règlements en matière de santé et de sécurité applicables en vertu des lois du Québec et des normes de la CNESST. Les parties doivent assurer un environnement de travail sécuritaire et rapporter tout incident à l&#x27;autre partie et aux autorités compétentes dans les vingt-quatre heures (24 h) suivant l&#x27;incident.</p>
<h2>24.1 Protocole d&#x27;escalade des incidents de sécurité</h2>
<p>Si le Sous-traitant identifie une situation sur le chantier qui présente un risque immédiat ou grave pour la santé ou la sécurité, il doit en aviser l&#x27;Entrepreneur Général par écrit sans délai.</p>
<p>L&#x27;Entrepreneur Général doit répondre par écrit dans les quarante-huit (48) heures suivant la réception de la notification. <p>Le Sous-traitant doit reprendre les Travaux suspendus dès qu&#x27;il est raisonnablement possible de le faire en toute sécurité.</p>
<h2>25. Respect de l&#x27;environnement</h2>
<p>Le Sous-traitant doit exécuter les Travaux conformément à toutes les lois et à tous les règlements applicables en matière d&#x27;environnement. Tout dommage environnemental causé par le Sous-traitant doit être rapidement réparé, à ses frais exclusifs.</p>

// ===== Helper: Render ONE HTML string to a PDF blob using html2pdf =====
// Each invocation renders its own offscreen canvas, so long contracts that exceed
// the browser's ~16384px canvas cap can be handled by splitting the HTML and
// calling this twice (see generatePdfBlob below).
async function renderPartToPdfBlob(htmlString, fileName) {
  if (!window.html2pdf) throw new Error('html2pdf library failed to load');

  var container = document.createElement('div');
  container.style.cssText = 'display: block !important; align-items: start !important; justify-content: start !important; min-height: 0 !important; margin: 0 !important; width: 7.3in; background: #fff; padding: 0; font-family: "Times New Roman", serif; font-size: 12pt; line-height: 1.6; color: #000; text-align: left; box-sizing: border-box; overflow-wrap: break-word;';

  var style = document.createElement('style');
  style.textContent = `
    * { box-sizing: border-box; }
    h1 { font-size: 16pt; text-align: center; margin: 0 0 20px 0; font-weight: bold !important; page-break-after: avoid; page-break-inside: avoid; }
    h2 { font-size: 13pt; margin: 16px 0 8px; color: #000; page-break-after: avoid; page-break-inside: avoid; font-weight: bold !important; }
    h3 { font-size: 12pt; margin: 12px 0 6px; color: #000; page-break-after: avoid; page-break-inside: avoid; font-weight: bold !important; }
    p { margin: 8px 0; text-align: justify; color: #000; page-break-inside: avoid; }
    ul { margin: 8px 0 8px 20px; padding: 0; page-break-inside: avoid; }
    li { margin: 4px 0; page-break-inside: avoid; }
    .center { text-align: center; }
    .indented { padding-left: 20px; }
  `;
  container.appendChild(style);

  var contentDiv = document.createElement('div');
  contentDiv.innerHTML = htmlString;
  container.appendChild(contentDiv);

  // Logo fix: fetch images through Supabase public URL so html2canvas can embed them
  var images = container.querySelectorAll('img');
  for (var i = 0; i < images.length; i++) {
    var img = images[i];
    if (img.src && img.src.includes('/logos/')) {
      try {
        var filePath = img.src.split('/logos/')[1].split('?')[0];
        var res = await fetch(SB_CONFIG.url + '/storage/v1/object/public/logos/' + filePath + '?t=' + new Date().getTime(), { mode: 'cors' });
        if (!res.ok) throw new Error('Logo fetch failed');

        var blob = await res.blob();
        var base64 = await new Promise((resolve, reject) => {
          var reader = new FileReader();
          reader.onloadend = () => resolve(reader.result);
          reader.onerror = reject;
          reader.readAsDataURL(blob);
        });

        await new Promise((resolve) => {
          img.onload = resolve;
          img.onerror = resolve;
          img.src = base64;
        });
      } catch (e) {
        console.warn('Logo download failed.', e);
        if (img.parentNode && img.parentNode.tagName === 'DIV') img.parentNode.remove();
        else img.remove();
      }
    }
  }

  // Let the browser paint any replaced images and stabilise heights
  await new Promise(resolve => setTimeout(resolve, 200));

  var opts = {
    margin: [0.6, 0.5, 0.6, 0.5],
    filename: fileName,
    pagebreak: { mode: ['css', 'legacy'], avoid: ['h1', 'h2', 'h3', 'p', 'li', 'ul'] },
    image: { type: 'jpeg', quality: 0.95 },
    // Each half renders its own canvas — scale 1.5 is safe per-half since the
    // canvas height is now well under the 16384px browser cap.
    html2canvas: { scale: 1.5, useCORS: true, letterRendering: true, scrollY: 0, scrollX: 0 },
    jsPDF: { unit: 'in', format: 'letter', orientation: 'portrait' }
  };

  return window.html2pdf().set(opts).from(container).output('blob');
}

// ===== Generate PDF blob from full contract HTML =====
// Splits on the `.lang-break` marker (EN/FR divider) into two halves, renders each
// half to its own PDF, then merges with pdf-lib. Single-language contracts skip the
// merge. Required for long bilingual contracts (20-30+ pages) that exceed the
// browser's ~16384px offscreen canvas cap in a single-pass render.
async function generatePdfBlob(htmlString, fileName) {
  if (!window.html2pdf) throw new Error('html2pdf library failed to load');

  var splitIdx = htmlString.indexOf('<div class="lang-break"');
  if (splitIdx < 0) {
    return renderPartToPdfBlob(htmlString, fileName);
  }

  var primaryHtml = htmlString.substring(0, splitIdx);
  // Strip `page-break-before: always` from the lang-break div since each half is
  // already its own PDF — the forced break would just create a blank leading page.
  var secondaryHtml = htmlString.substring(splitIdx).replace(/page-break-before:\s*always;?\s*/i, '');

  var [blob1, blob2] = await Promise.all([
    renderPartToPdfBlob(primaryHtml, fileName),
    renderPartToPdfBlob(secondaryHtml, fileName)
  ]);

  if (!window.PDFLib) {
    await new Promise(r => setTimeout(r, 500));
    if (!window.PDFLib) throw new Error('pdf-lib failed to load');
  }

  var { PDFDocument } = window.PDFLib;
  var merged = await PDFDocument.create();
  for (var blob of [blob1, blob2]) {
    var buf = await blob.arrayBuffer();
    var src = await PDFDocument.load(buf);
    var copied = await merged.copyPages(src, src.getPageIndices());
    copied.forEach(function (p) { merged.addPage(p); });
  }
  var mergedBytes = await merged.save();
  return new Blob([mergedBytes], { type: 'application/pdf' });
}

          if(rbqVal !== '') { APP.data[e.name] = rbqVal; syncRBQAliases(e.name, rbqVal); }
